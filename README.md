Beaconkeeper is a lighthouse-guidance game: you are the keeper of the last light on a rocky coast, and the fleet is coming home through fog and storm. Aim the beam with the mouse and light each ship so it steers for the safe channel — a ship in the dark holds its lane, its panic grows, and the rocks do the rest. Three wrecks ends the run. Five waves, fog thickening every wave, rain in the fourth, the storm in the fifth. A flare lights the whole sea for a few seconds, and a clean run of ships home builds a combo that pays.

You don't fight the sea. You light the way.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move the mouse to aim the beam, SPACE fires a flare, P pauses, M mutes, R restarts after a win or loss. Arrow keys (or A/D) turn the beam without the mouse.
